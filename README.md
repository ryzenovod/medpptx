# Технологические платформы здравоохранения — 2035

Статическая web-презентация для выступления по теме технологических платформ здравоохранения к 2035 году.

## Управление

- `← / →`, `PageUp / PageDown`, `Space` — слайды
- `F` — полноэкранный режим
- `S` — источники
- `Home / End` — начало / конец

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.

Сайт не требует npm, CDN или сетевых ресурсов и работает как статический набор файлов.
